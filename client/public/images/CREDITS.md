# Presentation image credits

These photographs are used only for site branding and module presentation. They are not images of registered samples, devices, or research results. Original files are retained apart from the requested image-service resize/compression; CSS crops are presentation-only.

- `cinnamon-hero.jpg`: **Neil P-A** — [A pile of cinnamon sticks on a dark surface](https://unsplash.com/photos/sQjNAZE-W6s), [Unsplash License](https://unsplash.com/license). Downloaded at 1800px, JPEG quality 85.
- `cinnamon-spices.jpg`: **Marion Botella** — [Cinnamon sticks and assorted culinary spices](https://unsplash.com/photos/uaHShoIDGeo), [Unsplash License](https://unsplash.com/license). Downloaded at 1000px, JPEG quality 80.
- `cinnamon-botanical.jpg`: **USDA**, [Cinnamomum verum1.jpg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Cinnamomum_verum1.jpg), identified there as public domain. Original 500×323px image.

The app footer includes these credits. Branding images fall back to the existing local `cinnamon.svg` illustration if needed, then to an accessible placeholder if both sources fail. Sample images never fall back to stock photos or synthetic sensor data: a failed sample image displays a preview-unavailable state.

- `cinnamon-example-baseline.jpg`, `cinnamon-example-current.jpg`: project photographs of cinnamon quills (iPhone, 15 Oct 2026), resized to 1200px, JPEG quality 85. Shown on the Image analysis page as labelled examples when a sample has no stored baseline/current image; they are not stored images of any registered sample.
